# TaskDocuments — поведение

Отображение дерева, документа и файлов — как в [OrderDocuments](../../OrderDocuments/docs/requirements.md).

## Статус

`versionData.statusName` — цветная метка (`Tag`) по `versionData.statusCode`. Коды — из справочника `doc_status`:

| `statusCode` | Название | Описание | Цвет |
|---|---|---|---|
| `NewDoc` | Новый | Документ добавлен в НКрК | синий |
| `InProgress` | В работе | Документ находится в работе у сотрудника | жёлтый |
| `InApprove` | Согласование | Документ отправлен на согласование | фиолетовый |
| `Actual` | Актуальный | Документ актуален, имеет актуальные данные, все согласования и подписания | зелёный |
| `Archive` | Неактуальный | Документ неактуален | серый |

Неизвестный код — серая метка.

## Редактируемые поля

- «Вид заверения», «Форма предоставления», «Способ подписания» — выбор из списка (`Select`), каждое в своей колонке.
- Редактируются только строки документов. Документ, пришедший в ответе `/taskList`, считается созданным.
- Права не проверяются: если пользователь видит компонент, он может редактировать.
- Варианты списка — `{поле}.List` из `GET /credit-doc/docTypeDict/{docType}`, свои для каждого типа документа. Подпись — `value`, иконка — как в OrderDocuments (`common/fields.tsx`). Очистить значение нельзя.
- Текущий код, которого нет в справочнике, выводится как есть, с иконкой по умолчанию.
- Пока справочник грузится — индикатор загрузки в селекте. Ошибка загрузки — селект подсвечен красным, в тултипе текст ошибки.

## Сохранение

- Сразу при выборе значения, без кнопки «Сохранить».
- Пока идёт сохранение и перезапрос `/taskList`, селект заблокирован и показывает загрузку.
- Ошибка — уведомление с названием документа и текстом ошибки, селект подсвечен красным, в тултипе текст ошибки, значение остаётся прежним. Подсветка снимается при следующем успешном сохранении этого поля.
